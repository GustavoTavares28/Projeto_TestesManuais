# 📂 Arquivos Originais

Esta pasta contém os arquivos utilizados durante a execução do projeto de Quality Assurance.

## 📊 Matriz de Testes

O arquivo `Exercícios Práticos — Testes Manuais em Sites.xlsx` contém a documentação original dos casos de teste criada durante a análise da aplicação.

## Como acessar o arquivo

O GitHub não realiza a visualização direta de arquivos Excel (.xlsx).

Para acessar a planilha:

1. Clique no arquivo `matriz-testes.xlsx`
2. Selecione a opção de visualização do arquivo (Raw/Download)
3. Faça o download para o computador
4. Abra utilizando:
   - Microsoft Excel
   - LibreOffice Calc
   - Google Planilhas

## Objetivo

Manter o arquivo original como evidência da documentação produzida durante o processo de testes.
