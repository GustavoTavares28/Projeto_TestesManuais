# BUG001 — Resultados de busca pouco relevantes

## Informações

**Aplicação:** Mercado Livre  
**Tipo:** Funcional  
**Severidade:** Média  
**Prioridade:** Média  
**Status:** Aberto

---

## Descrição

Ao pesquisar "computador", o sistema retorna diversos periféricos relacionados, ao invés de apresentar principalmente computadores.

---

## Passos para Reprodução

1. Acessar o Mercado Livre;
2. Clicar na barra de busca;
3. Pesquisar "computador";
4. Analisar os resultados.

---

## Resultado Esperado

O sistema deve apresentar produtos diretamente relacionados ao termo pesquisado.

---

## Resultado Encontrado

O sistema apresenta diversos periféricos de computador, reduzindo a relevância dos resultados.
